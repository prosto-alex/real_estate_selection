### Подбор жилых комплексов: сайт и Telegram-бот


**О проекте:**
Сервис помогает подобрать жилой комплекс (ЖК) по заданным параметрам. Данные берутся из одной Google-таблицы и показываются в двух форматах: на сайте и в Telegram-боте.

**1. Основные возможности сервиса**

Сервис позволяет подобрать жилые комплексы (ЖК) по заданным пользователем параметрам:

- **Город** — выбор города, в котором планируется покупка недвижимости.
- **Цена за м²** — минимальная и максимальная стоимость квадратного метра.
- **Этажность дома** — диапазон этажности от и до.
- **Тип дома** — выбор подходящего типа здания.
- **Высота потолков** — минимальная и максимальная высота.
- **Площадь квартиры** — желаемая площадь в квадратных метрах.
- **Бюджет** — максимальная стоимость квартиры в миллионах рублей.

### 2. Результаты подбора

Поиск ЖК запускается только после нажатия кнопки «Найти», а не автоматически при изменении параметров.

Для каждого найденного жилого комплекса отображается основная информация:

- город, район, класс ЖК и застройщик;
- тип дома;
- высота потолков;
- этажность дома;
- срок сдачи;
- стоимость квадратного метра;
- примерная стоимость квартиры;
- ссылка на страницу жилого комплекса на Циан.

**Расчёт стоимости квартиры:**
Если пользователь указал желаемую площадь, сервис дополнительно рассчитывает примерную стоимость квартиры по формуле: минимальная цена за м² × указанная площадь.

**Фильтрация по бюджету:**
Если указан максимальный бюджет, из результатов исключаются ЖК, в которых нет квартир, соответствующих этому ограничению.

Также предусмотрена кнопка сброса всех выбранных параметров, позволяющая быстро начать новый поиск.

### 3. Источник и обновление данных

Основной источник информации — Google Таблица, данные из которой автоматически загружаются на сайт и в Telegram-бот примерно раз в минуту.

При изменении информации в таблице не требуется вносить какие-либо изменения в программный код — сервис самостоятельно получает обновлённые данные.

Дополнительно предусмотрена резервная копия данных в формате `data.csv`. Если Google Таблица временно недоступна, сервис использует этот файл.

Пустые ячейки и значения «—» воспринимаются как отсутствие информации. Если пользователь указал определённый параметр для поиска, ЖК без данных по этому параметру не включаются в результаты.

### 4. Сайт-калькулятор

Сайт представляет собой одностраничное приложение, в котором реализованы:

- форма для ввода параметров поиска;
- фильтрация жилых комплексов;
- карточки с результатами подбора;
- карусель с фотографиями жилых комплексов.

Интерфейс адаптирован для использования как на компьютерах, так и на мобильных устройствах.

### 5. Telegram-бот

Бот разработан на Python с использованием библиотеки aiogram 3.

Основные возможности:

- управление через удобное меню с кнопками;
- ввод параметров поиска обычными сообщениями;
- поддержка различных форматов ввода, например: `200000-500000`, `от 15`, `до 3,2`;
- отображение результатов по 3 жилых комплекса на одной странице;
- переключение между страницами с помощью кнопок.

Бот работает по технологии Long Polling, поэтому для его запуска не требуются отдельный домен и настройка вебхуков. Для круглосуточной работы необходимо разместить его на сервере.

Выбранные пользователем параметры сохраняются в оперативной памяти бота. При его перезапуске настройки поиска сбрасываются.

### 6. Ограничения текущей версии

На данный момент в сервисе есть несколько ограничений:

- **Примерная стоимость квартиры.** Расчёт является ориентировочным и не отражает реальную стоимость конкретной квартиры. Он выполняется по минимальной цене за м², умноженной на указанную площадь.
- **Количество комнат и планировки.** Эти параметры пока не учитываются при подборе.
- **Дополнительные фильтры.** Поиск по классу ЖК, застройщику и району пока не реализован. При этом соответствующая информация отображается в карточках найденных объектов.
- **Хранение параметров в боте.** Выбранные настройки не сохраняются после перезапуска бота.
